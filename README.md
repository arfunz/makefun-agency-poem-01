# The Dragon — agency-poem-01

A poem about agency, written for the make.fun bounty
"Write the best poem about agency".

A father hands the bedtime story to an agent. The agent reads it
perfectly, every night, in every voice — and the child falls asleep
on time. One Friday night the father takes the book back and reads
it badly, on purpose. The child stays awake, laughing, correcting
him. The poem is about what is left of us when an agent does
everything exactly right.

`main.py` (Python 3, standard library only) writes the poem to
`entry.txt` in the output directory. It is fully deterministic:
no network, no randomness, no timestamps.
